# Sınav Koçum Pro 🎯

Sınav Koçum Pro, YKS (TYT, AYT, YDT) ve KPSS (Genel Yetenek - Genel Kültür) sınavlarına hazırlanan öğrenciler için geliştirilmiş, akıllı ve dinamik bir ders çalışma programı ve takip uygulamasıdır.

## 🌟 Özellikler

- **Dinamik Program Oluşturma:** Seçilen sınavlara (TYT, AYT, YDT, KPSS) göre her gün için özel çalışma programı otomatik olarak hesaplanır.
- **Minimum Süre Garantisi:** Bir sınavı çıkarsanız bile, günlük çalışma süreniz hedeflenen minimum çalışma saatinin (örn. 4 saat) altına düşmez; mevcut derslerin süreleri artırılarak telafi edilir.
- **Detaylı İstatistikler:** Çözülen deneme sınavı sonuçları, doğru/yanlış grafikleri ve net hesaplamaları.
- **Oyunlaştırma (Gamification):** Çalıştıkça kazanılan rozetler ve maskot (Sebo) ile artan motivasyon.
- **İlerleme Takibi:** Tüm derslerde konu bazlı tamamlama oranları ve durum takibi.

## 🚀 Kurulum ve Çalıştırma

Projeyi bilgisayarınızda çalıştırmak için aşağıdaki adımları izleyebilirsiniz:

```bash
# Repoyu bilgisayarınıza indirin
git clone https://github.com/Erhant-ant/sinav_kocum_pro.git

# Proje klasörüne girin
cd sinav_kocum_pro

# Gerekli kütüphaneleri indirin
flutter pub get

# Uygulamayı çalıştırın
flutter run
```

## 🛠 Kullanılan Teknolojiler

- **Flutter & Dart:** Çapraz platform mobil uygulama geliştirme çerçevesi.
- **Provider:** Durum (State) yönetimi.
- **Shared Preferences:** Yerel veri saklama ve oturum yönetimi.
- **fl_chart:** Grafiksel istatistik gösterimleri.
- **flutter_local_notifications:** Hatırlatıcı ve bildirimler.
